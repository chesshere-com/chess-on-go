Install

You need Go 1.25 or newer. The runtime package uses only the Go standard library. Dependencies in the root module support tests and comparisons.

go get github.com/chesshere-com/chess-on-go@v0.22.2

The import path is github.com/chesshere-com/chess-on-go; the package name is chessongo. Use the explicit alias below to keep examples easy to follow. Pin a released version in your application's go.mod.

Your first game

This complete program plays three half-moves, then prints the current FEN, side to move, and legal-move count.

{{example:quickstart}} 
go run ./examples/quickstart

The command above runs from a checkout of this repository. In your own module, save the program as main.go and run go run ..

These guides cover v0.22.2. See the release notes for upgrade details. The performance page names the exact commit measured.

Choose an API

You want to…UseWhy
Build a game or serverGame + TryMove*Validate input and maintain legal moves, check/mate, repetition, and PGN.
Read a positionBoardView, SnapshotInspect defensive copies without exposing mutable internals.
Branch an analysisCloneKeep an independent game with its current state and history.
Traverse many positionsSearchBoardReuse move buffers and skip game-status and PGN bookkeeping.

A Game is mutable and has no internal locking. Give each goroutine its own instance or clone, or synchronize access in your application. FEN captures a position, not its repetition history.

Use the CLI

The optional command-line tool validates a FEN, lists legal moves, or counts a move tree:

go run ./cmd/chessongo fen "4k3/8/8/8/8/8/8/4K3 w - - 0 1"
go run ./cmd/chessongo legal "4k3/8/8/8/8/8/8/4K3 w - - 0 1"
go run ./cmd/chessongo perft -depth 2 "4k3/8/8/8/8/8/8/4K3 w - - 0 1"

For a browser UI, use ChessHere's chessboard component and keep move validation in your Go service. The HTTP example shows a stateless request/response boundary.
