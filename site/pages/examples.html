Validate a move over HTTP

go run ./examples/http

This stateless example accepts a JSON object with fen and uci. It creates a game per request, returns HTTP 400 for bad input or HTTP 422 for an illegal move, and emits the resulting FEN, turn, and legal UCI moves.

{{example:http}} 
curl http://127.0.0.1:8080/move \
  -H 'Content-Type: application/json' \
  -d '{"fen":"rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR w KQkq - 0 1","uci":"e2e4"}'

For a real multiplayer game, own the authoritative position and history on the server, and check whose turn it is. A client-supplied FEN is useful for analysis tools; it does not carry repetition history or authenticate a move.

Feed the returned position into chessboard for rendering. Convert the legal UCI moves into its origin-to-destination map, and send promotion suffixes when the player chooses a piece.
