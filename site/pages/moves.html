ParseMoveSAN matches against legal moves in the current position. ParseMoveUCI parses a request, including variant-aware castling, but does not establish that the move is legal; apply it with TryMove. A UCI promotion needs its piece suffix.

SAN parsing tolerates trailing +, #, !, and ? annotations and zero-based castling such as 0-0. These suffixes are not assertions about the resulting position.

Make a move, then undo it

{{example:moves}}

MakeMove assumes its argument is legal. Prefer TryMove* at input boundaries. To undo captures, promotions, en passant, or castling, retain the exact legal move including its flags, and undo moves in reverse order. Do not substitute an arbitrary coordinate-only request for the actual move.

PieceAt's boolean indicates a valid square, not whether it contains a piece; an empty square returns EMPTY, true. Board() returns an array copy. Snapshot() copies public state and legal moves. Clone() independently copies the complete game state.

Square indices run from a8 = 0 to h1 = 63. Prefer ParseSquare and Square.String instead of relying on numeric indices or mutating the compatibility lookup maps. EnPassantSquare() returns zero when no target is present.

Game status and draw claims

Status() distinguishes an ongoing game, check, checkmate, stalemate, automatic draw, and variant win. IsTerminal() is useful at the application boundary. For variant wins, inspect Winner().
