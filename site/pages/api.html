Errors and compatibility

Use errors.Is with ErrInvalidFEN, ErrIllegalMove, or ErrInvalidMoveNotation. Use errors.As for *FENError and *IllegalMoveError when you need more detail.

Game fields are private. Prefer the method API above. Legacy lookup maps and low-level mutation helpers exist for compatibility; avoid building new integrations around them. Read the compatibility policy for versioning and persistence guarantees.
